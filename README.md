# App.Api
 Siliconmade uzmanlık eğitimindeki sekizinci projem: ASP.NET Core Web API ve HTML/JavaScript ile geliştirilen Öğrenci Bilgi Sistemi. CRUD işlemleri yapar. Backend’de EF Core, Bogus, server-side validasyon, CORS; frontend’de HTML, CSS, JavaScript (fetch API) ve client-side validasyonlar var.
